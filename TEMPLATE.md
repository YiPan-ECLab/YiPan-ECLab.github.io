# Template provenance

The site now uses **AcadHomepage**, the exact template used by the reference site.

- Upstream: https://github.com/RayeRen/acad-homepage.github.io
- Upstream commit: `2cc1577eeaf2f74dede6d016a70722dbd409ea2f`
- Visual reference: https://zwq2018.github.io/
- Reference source: https://github.com/zwq2018/zwq2018.github.io (a fork of the upstream above)
- License: MIT, Copyright (c) 2022 Yi Ren, retained in `LICENSE.acadhomepage`.

AcadHomepage's Sass, font assets, and default two-column page structure are reused.
Personal content, accessible navigation, paper data rendering, author highlighting,
search, and BibTeX controls are customized for Yi Pan. No biography, photographs,
publication figures, tracking IDs, or research claims from the reference author are reused.
The original Academic Pages license remains in `LICENSE` for retained dependencies.
Font Awesome license notices are retained with its source files.
